## How I think about systems

- **Architecture before complexity.** Clear agent boundaries and explicit handoffs before adding tools.
- **Evaluation before shipping.** Generated output needs measurable checks and visible failure modes.
- **Infrastructure enables reliability.** Structured logging, tracing, and observability catch problems in production.
- **Ownership compounds.** Build systems you'd run yourself—no black boxes, no "it worked in testing."
